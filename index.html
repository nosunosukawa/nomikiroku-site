のみきろく

薬局でもらう一包化の分包紙と同じ「朝」「昼」「夕」「寝前」のまとまりで、 お薬の記録をつけるiPhoneアプリです。5種類飲んでいても、朝は1タップで終わります。 お知らせから、アプリを開かずに記録できます。

サポート

連絡先

ご質問・不具合のご報告・お薬の名前や表示の指摘はこちらへ: nosunosukawa@gmail.com

個人で開発しています。全部読みます。返信は1〜2日いただくことがあります。 お知らせが鳴らなかったときは、お薬の名前・時点（朝／昼／夕／寝前）・ 鳴らなかった日を書いて送ってください。設定画面の「通知の状態」に出ている 数字（予約されている数・最後に作り直した）も一緒にいただけると原因が絞れます。

だいじな注意

このアプリは、お薬について何も判断しません

記録とお知らせをするだけです。飲み合わせの確認も、飲み忘れたときの対処も示しません。 お医者さんや薬剤師さんの代わりにはなりません。

体調が悪いときは、アプリを見ずに医療機関へご連絡ください。 いつもと違うと感じたときは、かかりつけの医療機関にご相談ください。

お薬の分類名は、厚生労働省の薬価基準収載品目リストに書かれている名前を そのまま転記しているだけで、「何のためのお薬か」をアプリが説明することはありません。

よくある質問

無料でどこまで使えますか？

お薬の時間のお知らせと、飲んだ記録は、これからもずっと無料です。 お薬の登録は種類の制限なし、手帳は全期間見返せます。通院の予定と体調メモ、 広告が出ないことも無料の側です。

有料の「のみきろく Plus」でできるのは、記録を持ち出すことと、 先を見ることです。お薬の残りと終わる見込みの日、離れて暮らすご家族との共有、 入院や災害のときに渡せる紙（PDF）、記録の書き出し（CSV）。

最初の30日は全部の機能をお試しいただけます。自動で更新されることはなく、 カードの登録も要りません。飲み忘れを防ぐ機能にお金を払っていただく作りにはしていません。

お知らせが途中で来なくなりませんか？

iPhone は1つのアプリにつき64件までしかお知らせを覚えていられません。 お薬1種類ごとに予約する作りだと、種類が多い方は1週間ほどで枠が尽きて、 そこから先が黙って鳴らなくなります。

のみきろくは時点ごとに1件だけ予約し、毎日飲むお薬は 「繰り返し」の予約で1件に収めています。予約の数が上限に近づいたら、 遠い予定から自動で削って入れ替えます。

そのうえで、いま何件予約できているかを設定画面に出しています。 止まっていることに気づけない作りにはしません。

お知らせを押すだけで記録できますか？

できます。お知らせの［飲んだ］を押すと、アプリが開かないまま、 その時点のお薬すべてに記録が付きます。あとで［あとで］を押すと、 しばらくしてからもう一度お知らせします。

お知らせの文面には、既定でお薬の名前を出していません。 ロック画面に薬名が出ると、ご病気が他の方に伝わってしまうためです。 設定で表示に変えることもできます。

お薬が登録できません／名前が見つかりません

厚生労働省の薬価基準収載品目リスト（内用・注射・外用）から 12,400件をアプリに入れてあります。ひらがな・カタカナ・半角の どれで入力しても引けます。それでも出てこないときは、 手で名前を入れて登録できます。登録できないお薬はありません。

お薬手帳のQRコードの読み取りは、実際の調剤明細で確かめられるまで 入れていません。推測で作って読み違えると、飲む量が違って記録されます。

夜中に飲んだお薬が、翌日の記録になってしまいます

1日のはじまりを何時にするかを、設定 →［1日の区切り］で 0時から6時まで選べます。既定は4時なので、深夜3時に飲んだ寝る前のお薬は 前の日の記録になります。

離れて暮らす家族と共有できますか？

できます。設定 →［ご家族と共有する］から、共有される内容を ご確認いただいたうえで、LINE・メール・AirDropで招待を送れます。 共有できるのはお一人までです。

ご家族の画面には、今日の時点ごとの記録・直近14日・お薬の一覧・お薬の残り・ 次の受診の予定が出ます。ご家族が代わりに記録することもできて、 その分には「家族が記録」と印が残ります（お医者さんに渡す紙にも出ます）。

体調メモを共有から外す設定があります。外したときは、 そもそも送られません。共有はいつでも1タップでやめられて、 やめるとご家族の画面からはすぐに見えなくなります。

記録が届かなくなったときのために、ご家族の画面には 「最終受信」を常に出しています。1日以上・3日以上届かないときは、 その旨をご家族の画面にお知らせします。 なお、飲んでいないことをご家族に自動でお知らせすることはありません。 見張られている感じにしないためです。

入院のときに渡す紙は作れますか？

作れます。おくすり →［紙に出す・表で出す］から3種類出せます。

  • 持参薬リスト（A4・1枚）— 入院・転院・介護施設で「いま何を飲んでいるか」を渡す
  • 災害時のお薬カード（名刺サイズ4面）— 切ってお財布に入れておく
  • 服薬の記録（A4・1か月）— 受診のときにお医者さんへ渡す

プリンタがあれば［印刷する］でそのまま送れます。無い場合は［共有する］→ ［ファイルに保存］で保存して、コンビニのマルチコピー機で印刷できます。

記録は表（CSV）でも書き出せます。ExcelやNumbersでそのまま開けます。

お薬の残りの数が合いません

記録していない分は差し引かれないので、実物とはずれていきます。ずれて当たり前という 前提の作りにしてあり、おくすりの画面の［手元の残りを数えて入れる］で いつでも数え直せます。

「飲んだ」と記録した分だけを引いています。記録なしの分を 「たぶん飲んだ」として引くことはしません。推測を混ぜると、 お薬が終わる見込みの日が信用できなくなります。

買ったのに、有料の機能が使えません

購入時と同じ Apple ID でサインインした状態で、 設定 →［購入したものを復元する］を押してください。 購入は Apple ID に紐づくので、機種を変えても引き継がれます。

機種を変えるときは？

記録はご自身の iCloud に保存されているので、新しい iPhone で同じ Apple ID に サインインしてアプリを入れると戻ります。

戻るのは iCloud に保存できた分までです。 iCloud にサインインしていない場合や空きが足りない場合は、その端末の中だけに 残ります。いまどちらの状態かは、設定の［iCloudへの保存］に常に出しています。 念のため、大事な記録は表（CSV）で書き出して保存しておくこともできます。

文字が小さくて読めません

設定 →［文字の大きさ］で、このアプリの中だけ大きくできます。 iPhone 本体の設定を触る必要はありません。選んだ結果はその場で見本に反映されます。

収集しません

開発者は、あなたの記録を見られません

アクセス解析も、広告も、開発者のサーバーもありません。アカウント登録も不要です。 お薬の名前・飲んだ記録・体調メモが、開発者や第三者に渡ることは一切ありません。

記録はご自身の iCloud（Apple のアカウント）に保存されます。 これは端末を変えても記録が消えないためのもので、開発者が中身を見ることはできません。 ご家族との共有をオンにしたときだけ、共有したお一人に、 ご確認いただいた内容が見えるようになります。
